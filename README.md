# Cognifyz Technologies — Restaurant Data Analysis (Data Analyst Internship)

This repository contains the data analysis work completed during my Data Analyst Internship at **Cognifyz Technologies** (June–July 2026). The project explores a restaurant dataset across multiple analytical levels — from descriptive statistics to relationships between pricing, services, and customer engagement.

## 📁 Project Structure

| File | Description |
|---|---|
| `LEVEL_2.ipynb` | Ratings distribution, cuisine combinations, geographic analysis, restaurant chain identification |
| `LEVEL_3.ipynb` | Review/rating-text analysis, votes analysis, price range vs. service availability |
| `dataset.csv` | Restaurant dataset used for all analyses |
| `*.png` | Saved visualizations generated during analysis |

## 🔍 Analysis Breakdown

**Level 2**
- **Task 1 — Restaurant Ratings:** Distribution of aggregate ratings across the dataset
- **Task 2 — Cuisine Combination:** Most common cuisine pairings/combinations offered by restaurants
- **Task 3 — Geographic Analysis:** Mapping restaurant locations using latitude/longitude
- **Task 4 — Restaurant Chains:** Identifying restaurants that operate as chains (multiple outlets)

**Level 3**
- **Task 1 — Restaurant Reviews:** Sentiment proxy analysis using the `Rating text` field (Excellent/Very Good/Good/Average/Poor), since the dataset had no raw review-text column
- **Task 2 — Votes Analysis:** Restaurants with the highest and lowest vote counts; relationship between votes and rating
- **Task 3 — Price Range vs. Services:** Relationship between price range and availability of online delivery / table booking
